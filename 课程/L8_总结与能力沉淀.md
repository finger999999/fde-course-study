# 第八课 · 总结与能力沉淀

> **学习版说明**：前七课收"手艺"，这一课收"能不能把手艺交给你"。三件事：把经验固化成组织能力、把团队编成和 90 天计划定下来、通过路演验收定级。

## 学习目标

- [ ] 掌握"固化三问"心智模型，会评估一个平台成不成熟
- [ ] 说清校验器在守什么、promote 为什么不自动提交
- [ ] 记住三条一票警示，完成诚实的自我定级

## 一、能力沉淀：从"我做过"到"组织有这个能力"

前七课你做的是**这一个项目**；这一节做的是**下一个项目**——把这次反复做的动作，沉淀成下次开箱即用的工具。

### ⭐ 固化三问（本课唯一要带走的心智模型）

任何一条你反复叮嘱新人的纪律，都问它三个问题：**能不能固化？固化成什么？谁来跑？**

| 档 | 例子 | 固化成什么 | 人力成本 |
|---|---|---|---|
| **全固化** | "跨域不许越界写" | 结构校验器，编译期自动 | **零人力，永不疲劳** |
| **全固化** | "引用的脚本必须存在" | 校验脚本 | 零人力 |
| **半固化** | "关键数字锚在单点" | BRIEF + 装配期检查，人复核 | 一道人工闸 |
| **半固化** | "不确定就显式挂账" | 文档挂账约定 | 一道人工闸 |
| **未固化** | 只活在你脑子里的那条 | 无 | **全靠自觉，请假即崩** |

> **评估一个平台成不成熟，就看它把你多少条纪律固化进了校验器。** 真实项目能做到 1 名 FDE + 智能体编队顶掉传统 5 人数周，不是因为手快，是因为绝大部分一致性纪律被搬进了编译期和装配期。

### 沉淀四步链路

```
spec-generate（唯一零确认点的一步；边界之外一律不动——这是可预测性的来源）
  → build-skills（初稿不是成品；工具不会自己给自己发合格证）
  → 校验器（"什么叫做完了"的操作定义：结构 7 类 + 逐技能 9 类 + 依赖 3 组）
  → promote（里程碑存档）
```

**promote 的"不做清单"比"做"更值得记**：它不自动 git commit——**因为提交是人的决定**；它不顺手清理计划外的东西——**边界之外一律不动**。

**活证据**：采购报价优化插件 `fund-review` 就是从真实交付里反向沉淀出来的——一个项目里反复做的动作，变成下个项目直接调用的插件。

🔔 **现在轮到你回答**：你们这五天做的动作，**哪一个值得沉淀成插件？** 追问：它是"下个项目还会再做一遍"的动作吗？还是只有你们这个命题才有？**为做插件而做插件，拿不到加分。**

## 二、OPC 边界回收与团队编成

第一课画的线在这里回收：可替侧（智能体能放大的）与必须人扛侧（C7）的边界不变，变的是你现在已经能亲手走完全程。

**团队不是"招一堆全能 FDE"（那是幻想），而是非对称编队**：

| 角色 | 提供什么 |
|---|---|
| **Lv.3 主理** | **判断和责任**——编队的"判断中枢" |
| **Lv.1 见习** | 手数和成长通道——承接单一环节，在真实项目里练 |
| **平台组** | **杠杆**——维护建模管线，把方法论固化成工具 |

> 三者缺一，项目不可复制。**没有平台组，Lv.3 也会退化成一个更累的架构师。**

规模化的前提不是"招更多人"，而是：下一个项目关键指标达到基线 + Lv.1 里有人升到 Lv.2。

## 三、路演与三条一票警示

路演每组 20 分钟，用八维评审卡评分（评审卡只有一个真相源，两处维护一张表必然漂移——这正是第六课"编号权归装配"同一条纪律）。**比的是判断，不是美工。**

### ⚠️ 三条一票警示（触发任一条即不通过）

| 警示 | 真实形态（都不是明目张胆造假） |
|---|---|
| **① 编造查不到的文号（B-10）** | "看起来像标准号就用"——问一句"这个号你在哪查到的"，当场就露 |
| **② 把别处模板的数字当自己的（B-11）** | 模板复用时把上一个项目的数字一起带过来 |
| **③ 把目标值 / Mock demo 说成已实现** | **不是撒谎，是不说**——所以规定 demo 必须先念 Mock 清单再演 |

> ⭐ **三条其实是同一条：空缺可以补，编造无法挽回。**
> 七课工具练的是手艺，**这一条练的是能不能把手艺交给你。**

## 四、结课定级

| 等级 | 含义 |
|---|---|
| **Lv.1 见习** | 能在指导下承接单一环节 |
| **Lv.2 胜任** | 独立完成认知侧全链条，交付物需一次复核 |
| **Lv.3 主理** | 主持项目、设闸、对客户承诺负责，并能带 Lv.1 |

- 定级**看证据不看感觉**：举不出"我在压力下真做过留白不编造"这个例子的人，不该给自己填 Lv.3
- 多数人第一次停在 Lv.1，这是正常的；**装作 Lv.2 才是危险的**
- 当堂填一张**差距清单**带走：诚实回答"这个我补不了"的人，比嘴上说"我都行"的人更接近 Lv.3

## 自测

1. 固化三问是哪三问？你的项目里有哪条纪律还停在"未固化"？
2. promote 为什么不自动提交？
3. 三条一票警示的共同判据是什么？
4. 你给自己定哪一级？证据是什么？
