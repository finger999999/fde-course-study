# 第三课 · 如何正确采集信息

> **学习版说明**：这是唯一一个"错了之后无法在下游补救"的环节。环境装错了能重装，域切错了能返工，但信息在源头丢了、歪了，后面每一步都在错误的地基上精雕细琢——**而且没人知道它曾经存在过**。

## 学习目标

- [ ] 画出信息衰减链，说清每个工具防的是哪一道衰减
- [ ] 区分"全"和"准"两个标准，知道为什么"不准"更危险
- [ ] 会用两类模板（A/B），并产出一份三层齐全的 `_INPUT.md` 输入包

## 一、信息衰减链（本课的总地图）

```
客户脑子里的 → 客户说出来的 → 你听到的 → 你记下来的 → 你写进模板的 → 智能体读到的
   ①隐含前提    ②表述能力     ③注意力      ④转译损失     ⑤结构化损失    ⑥理解偏差
```

**六道衰减。本课的每一个工具，都是在其中某一道上设的保真措施。**

> **难听话**：交付失败十有八九不是败在建模或写作，是败在**第一次和客户谈完之后，你以为你听懂了**。

## 二、两个标准：全 ≠ 准

| 标准 | 定义 | 靠什么保证 | 失败长什么样 |
|---|---|---|---|
| **全** | 该问的都问了 | checklist（覆盖度） | 后面突然冒出一个没人考虑过的约束 |
| **准** | 客户原话没被你的转译污染 | 原话留存（保真度） | 所有推导都建立在你的误解上，**而且看起来很自洽** |

⭐ **不准比不全更危险：漏了会暴露，歪了不会。** 漏掉的东西迟早会撞出来；理解歪了的东西，会一路顺畅地长成一整套自洽的错误方案——直到评审那天才爆。

## 三、六个工具（每个对应衰减链上的一环）

### 工具① · 电梯演讲（防"你以为你懂了"）

30 秒四句话说清这个项目。**判据不是"说得好听"，是邻组能不能复述回来。** 客户皱眉 = 你当场就发现了偏差，而不是三周后。

### 工具② · 5W2H 覆盖 checklist（保"全"）

Who / What / When / Where / Why / How / How much——**七项缺一，就是"不全"**。答不上来的项标"待客户确认"，最怕的是缺项而不自知。

### 工具③ · 利益相关者地图（保"全"里最容易漏的一块）

四栏：谁出钱 / 谁使用 / 谁验收 / **谁反对**。"谁反对"必须问——把反对者提前识别出来，等于在流程里提前设了一道闸。

### 工具④ · 原话留存（保"准"）

客户的原话进"事实层"，**你的转译不许混进去**。"用户需要土壤检测功能"是你的转译；用户原话可能是"地里该不该浇水，我心里没底"——里面的约束完全不同。

### 工具⑤ · 两类模板（先判用哪类）

| | 模板 A · 平台立项型 | 模板 B · 大模型能力型 |
|---|---|---|
| 适用 | 有运营盘的平台项目（→ 多半模式二） | 大模型能力/应用类（→ 多半模式一） |
| 结构 | 六段：概览 / 角色 / 价值 / 商业模式 / 拓展 / 名称 | 定位 / 用户及场景 / 数据需求 / 能力边界等 |

**最常见的判断错误：只写 B 不写 A。** 角色只列"用户""管理员"是软件角色不是业务角色，画像必然空洞。价值写"提升效率、降低成本" = 不可量化 = 财务测算那步直接断链。

⚠️ **复用模板的红线（反例 B-11）**：有项目把另一个模板的数字整段带过来——模板结构可以复用，**数字不可以**。数字无主 = 编造，**比空缺更有害**，这是结课路演的一票警示。

### 工具⑥ · `_INPUT.md` 输入包（本课落点 ⭐）

把采集到的一切压成三层，第四课直接喂给智能体：

```
① 事实层：客户原话摘录（不加工）
② 口径层：术语表 · 关键数字（唯一真相源，下游一律引用不重算）· 禁用词 · 成熟度标注
③ 任务层：要做什么 · 产出格式 · 不许做什么（必须有禁令）
```

**只有事实层 = 只完成了三分之一。** 口径层缺了，第四课跑出来的画像会空洞、术语每次都不一样；任务层没禁令，智能体就会自由发挥。

## 四、checkout 关键项

- [ ] 模板选型说得出理由（A / B / A+B）
- [ ] 价值段至少 1 处带数字（时间/人力/金额），且**每个数字能答"是谁的、从哪来"**
- [ ] 输入包三层齐全，任务层有"不许做什么"
- [ ] 每类用户的典型提问 ≥10 条，且是原话不是转译
- [ ] 拿不准的地方标"待客户确认"，没有把猜测写成客户需求

> 你说不清"谁在什么时候因为什么做了什么动作"、也列不出"他会怎么问"，**就还没有项目，只有一个愿望。别把愿望丢给智能体，它会很客气地帮你把愿望写成 100 页。**

## 自测

1. 为什么"不准"比"不全"更危险？（漏了会暴露，歪了会自洽地长到最后）
2. 利益相关者地图最容易漏哪一栏？（谁反对）
3. 输入包哪三层？缺口径层会怎样？
4. B-11 反例错在哪？（复用模板时把数字一起带过来 = 编造）
